# Beyond Strategy prospective validation protocol

Frozen before generating evaluation policies or viewing outcomes on 2026-10-18. This is a local prospective specification, not an external preregistration. The implementing analyst knows both generator families. The computational identity barrier withholds the policy identity map until measurements and predictions are saved and hashed; it does not establish investigator blindness.

## Population and transfer

Generate 32 independent seeds for each family. Cohort A uses chance-sampled tabular counterfactual regret minimization with 80 simultaneous regret-matching iterations, six independent uniformly sampled rank decks per iteration, zero regrets, and reach-weighted average behavioral policies. This is a finite-budget CFR population, without a convergence claim. Cohort B uses equity/pot-odds logit policies with independently sampled strength, aggression bias, temperature, and history-slope parameters. Neither family has PCC weights. Policies remain fixed at evaluation. CFR samples use seeds 730001+101*i; logit parameters use 930001+101*i, i=0,...,31. The opaque ID permutation uses 71201; bootstrap uses 918232 and 918233.

Train on A and test on B, and separately train on B and test on A. No policy, training trajectory, action row, or seed crosses a train/test boundary within a direction. The same policies are reused in the reverse direction and the analysis controls the entire comparison family jointly. A replicate is a complete independently generated policy, not a hand or information set. Shared exact reference opponents and enumeration panels are fixed; inference conditions on them.

## Measurements and endpoints

Split complete public betting histories by SHA256 of the fixed salt and history, modulo two. All private-card and seat variants of a history stay together. Measurement features use panel 0; matched-card action response uses panel 1. Average each measurement uniformly over information sets, rather than by stochastic visitation frequency. There are no observed terminal returns in the candidate measurements.

The baseline contains five action frequencies, normalized policy entropy, aggression, expected one-step regret under an exact uniform continuation reference, twelve public-history stratum summaries of five frequencies, entropy and equity-aggression interaction, and both exact best-response values and NashConv/2. All strata, including empty ones, have fixed positions. Exploitability intentionally uses the full behavioral profile as a conventional comparator; other measurement features use only panel 0.

The candidate PCC bundle contains three new operational reference scores. Pressure is expected (uniform opponent fold probability + commitment ratio)/3 when an action immediately presents an opponent with a wager; response compression under the uniform model is zero. Control is expected exp(-one-step regret/(pot+bet size)). Chaos is normalized policy surprisal times max(0,1-regret/(pot+bet size)), averaged over actions and states. These operational candidates adapt existing reference-index, efficiency and effective-surprisal ideas; they do not test latent weights, full feedback Control, or all historical estimators. The reference opponent and continuation never depend on generated policy identities or target outcomes.

Three independently computed endpoints are: exact seat-balanced net chips per hand against a fixed tight logit opponent (strength=5, bias=-1.5, temperature=.5, history slope=0); exact value against a fixed loose opponent (2,1.5,.8,0); and held-out-panel mean total variation between private-rank 0 and 2 action distributions holding public history, seat and public card fixed. Full game value integrates all chance deals, including states outside the measurement panel; this is the independent outcome, not an input to candidate features. Conventional exploitability is related to value by design and is included to make the comparison demanding.

## Prediction and inference

Fit ridge regression with an unpenalized intercept and penalty 10, using only training-family means and standard deviations. Compare the same baseline model with and without all three candidate columns. No hyperparameter selection or outcome-dependent feature selection. Report raw test MSE and per-policy paired error differences normalized by the original training outcome variance. Positive improvement favors the candidate bundle. The 0.01 margin is one percent of that variance, not one percent of baseline MSE.

For each of six direction-by-endpoint comparisons, test superiority H0: mean improvement <=0, and test no meaningful benefit H0: mean improvement >=0.01 against improvement <0.01. The second test excludes a specified benefit; it cannot prove an exactly zero effect. Resample whole training policies and whole testing policies independently 3999 times, refitting both models on identical resampled policies and evaluating paired predictions on identical resampled testing policies. Use centered bootstrap null tail probabilities with the plus-one adjustment. These are approximate population-bootstrap tests. Record marginal percentile 95% intervals and one-sided 95% upper bounds. Apply Holm correction once across all 12 one-sided tests at alpha .05. Preserve every failed superiority or no-benefit test. No intermediate outcome peeking or later tuning is permitted within v1.

## Fixed Chaos best response

Evaluate the source score Chaos mixture (0.1,0.1,0.8), temperature .35, as an immutable behavioral snapshot with empty frozen opponent and action histories. Enumerate every information set and check that all hidden states in it produce identical action probabilities. This snapshot differs from the history-updating policy used in old tournaments, so results must not be substituted for historical Chaos exploitability.

Compute exact information-set best responses against this target for both seats. Independently derive a response table through recursive policy iteration and execute it against the target. Reconstruct Leduc rules in a separate dictionary-state evaluator using 120 physical-card chance triples; exhaustively compare transitions, public information keys, legal actions, terminal net payoffs, and chance probabilities to the solver's 90 rank-deck tree. Re-evaluate target and best-response profiles in that evaluator. This supplies internal rule/algorithm cross-checks; it is not OpenSpiel or other external replication.

## Provenance and checks

Refuse existing output directories. Before generation, freeze the configuration, seeds, Git base revision, worktree status, exact source hashes, Python and NumPy versions. Chain timestamped events for pipeline freeze, opaque policy generation, measurement freeze, prediction freeze, identity reveal in sorted opaque-ID order, and completion. Check source hashes before reveal and check measurement/prediction/identity commitments. Hash every pre-existing file under validation before running and verify it afterward.

Focused tests cover label/metadata invariance, early reveal rejection, frozen-code tampering, write-once artifacts, held-out-feature isolation, hidden-state invariance, dictionary and policy ordering, training-only preprocessing, affine feature units, seed separation, duplicated chance-state dependence, Holm family size, exhaustive rules and independently executed best responses. All observed failures, including scientific null results and unmet blinding/external-replication requirements, belong in the final report. No submission or publication is authorized.
